# Antigravity Rules

Read and follow all instructions in `CLAUDE.md` (project conventions) and `STATUS.md` (current session state) in the project root. These are the single source of truth for this project.

## Session Protocol
- Update STATUS.md after milestones, before commits, and on "wrap up".
- Update `.context/memory.md` when discovering gotchas.
- Always tell the user when you update these files.

## Skills
Skills are shared between Claude Code and Antigravity via `.antigravity/skills/` (junction to `.claude/skills/`). Use them as documented in each skill's SKILL.md.
